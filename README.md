# vitalog — 血圧ノート

毎日の家庭血圧を記録・グラフ化・分析し、データに合わせた生活改善のヒントを表示するシンプルなWebアプリです。

- インストール不要・ログイン不要。スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます
- 記録は端末のブラウザ内（localStorage）だけに保存され、外部には送信されません
- 「履歴」タブからバックアップ（JSON）・CSVの保存と復元ができます

※分析は記録から機械的に計算した目安であり、診断ではありません。

## Googleスプレッドシート連携（任意）

`config.js` の `googleClientId` に Google Cloud で発行した OAuth クライアントID を設定すると、「履歴」タブに連携機能が表示されます。
権限は `drive.file`（アプリが作成したファイルのみ）だけを使います。詳しくは [プライバシーポリシー](privacy.html) を参照してください。
